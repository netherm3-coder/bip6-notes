# Блокнот для Amazfit Bip 6

Нотатки прямо на годиннику: заголовок + текст, власна клавіатура УКР / ENG / 123. Усе зберігається на годиннику, телефон для роботи не потрібен.

## Клавіатура

- Літера вводиться, коли **відпускаєш** палець. Поки тримаєш — над пальцем видно збільшену літеру; можна довести палець до сусідньої клавіші. Відвести палець угору на текст — скасувати.
- Довге натискання: **г → ґ**, **, → .**, **. → ?**, **' → "**. Маленька підказка в куті клавіші.
- **⇧** — велика літера, двічі швидко — Caps Lock. Після «. », «! », «? » і нового рядка велика літера вмикається сама.
- Два пробіли поспіль — крапка.
- **⌫** — стерти символ, утримати — стерти слово.
- **🌐** — УКР/ENG (вибір запам'ятовується), **123** — цифри й символи, там же **↵** — новий рядок (лише в тексті).
- **✓** — зберегти. Кнопка «Назад» на корпусі теж зберігає. Свайп убік у редакторі вимкнено, щоб випадково не закрити його під час набору.

Курсор завжди в кінці тексту. Ліміти: заголовок 80 символів, текст 4000.

## Встановлення через QR-код

Потрібні телефон із Zepp app і **другий екран** для показу QR (ПК, планшет, інший телефон): камера телефона не відсканує його власний екран.

1. **Режим розробника в Zepp:** Профіль → Налаштування → Про програму (Profile → Settings → About) → 7 разів тапни по логотипу Zepp.
2. **Codespace:** на сторінці цього репозиторію → **Code** → **Codespaces** → **Create codespace on main**. Перший запуск 2–3 хв (встановлюється Zeus CLI). Термінал: меню ☰ → Terminal → New Terminal, якщо його не видно.
3. **QR-код** — у терміналі:
   ```
   npm run qr
   ```
   Першого разу скрипт попросить увійти в Zepp: відкрий посилання, увійди **тим самим акаунтом, що в Zepp app**, браузер покаже помилку «localhost» — скопіюй повну адресу з рядка браузера й встав у термінал. Якщо спитає пристрій — Amazfit Bip 6, Enter.
   Після збирання QR з'явиться в терміналі та у файлі **qr.png** (корінь проєкту).
4. **Покажи QR на другому екрані:** відкрий цей codespace там (github.com → Codespaces) або завантаж `qr.png` (довге натискання на файлі → Download) і перешли на той пристрій.
5. **Скануй:** Zepp → Профіль → Режим розробника → значок сканера вгорі праворуч → наведи на QR → встановити. «Блокнот» з'явиться в списку програм годинника.

QR має термін дії (дата — у терміналі над QR). Якщо скан не спрацював — `npm run qr` ще раз.

**Без другого екрана:** якщо в сканері Zepp є кнопка вибору фото з галереї — вибери завантажений `qr.png`. Якщо немає — встанови через Bridge: Zepp → Режим розробника → **+** → **Bridge**, у терміналі `zeus bridge`, далі `connect` і `install`.

Після встановлення codespace можна зупинити (Code → Codespaces → ⋯ → Stop codespace), щоб не витрачати квоту GitHub.

## Оновлення програми

Змінив код → `npm run qr` → скануй новий QR. `appId` у `app.json` не змінюй: за ним годинник впізнає програму, і нотатки зазвичай лишаються після оновлення.

## Якщо щось не так

- **Не ставиться на годинник:** акаунт входу в терміналі й у Zepp app мають збігатися.
- **Вхід застарів:** `npm run qr` сам попросить увійти знову (або `npm run login`).
- **Сканер не бачить QR:** збільш яскравість другого екрана, відкрий `qr.png` на весь екран.

## Структура

- `page/index.js` — список нотаток
- `page/view.js` — перегляд, редагування, видалення
- `page/edit.js` — редактор
- `keyboard/` — клавіатура: розкладки, логіка тексту, віджети й дотики
- `utils/store.js` — збереження в `notes.json` на годиннику
- `.tools/qr.js` — `npm run qr`: збирання, завантаження в Zepp і QR-картинка (папка з крапкою, щоб Zeus не намагався зібрати ці скрипти для годинника)
- `.tools/zepp-login.js` — вхід у Zepp для Codespaces

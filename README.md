# Блокнот для Amazfit Bip 6

Нотатки прямо на годиннику: заголовок + текст, власна клавіатура УКР / ENG / 123. Усе зберігається на годиннику, телефон для роботи не потрібен.

## Клавіатура

- Літера вводиться, коли **відпускаєш** палець. Поки тримаєш — над пальцем видно збільшену літеру; можна довести палець до сусідньої клавіші. Відвести палець угору на текст — скасувати.
- Довге натискання: **г → ґ**, **, → .**, **. → ?**, **' → "**. Маленька підказка в куті клавіші.
- **⇧** — велика літера, двічі швидко — Caps Lock. Після «. », «! », «? » і нового рядка велика літера вмикається сама.
- Два пробіли поспіль — крапка.
- **⌫** — стерти символ, утримати — стерти слово.
- **🌐** — УКР/ENG (вибір запам'ятовується), **123** — цифри й символи, там же **↵** — новий рядок (лише в тексті).
- **✓** — зберегти. Кнопка «Назад» на корпусі теж зберігає. Свайп убік у редакторі вимкнено, щоб випадково не закрити його під час набору.

Курсор завжди в кінці тексту. Ліміти: заголовок 80 символів, текст 4000.

## Встановлення з телефона (без ПК)

1. **Режим розробника в Zepp:** Профіль → Налаштування → Про програму (Profile → Settings → About) → 7 разів тапни по логотипу Zepp.
2. **Codespace:** на сторінці цього репозиторію → **Code** → **Codespaces** → **Create codespace on main**. Перший запуск 2–3 хв (встановлюється Zeus CLI). Термінал: меню ☰ → Terminal → New Terminal, якщо його не видно.
3. **Вхід у Zepp** у терміналі:
   ```
   npm run login
   ```
   Відкрий посилання, увійди **тим самим акаунтом, що в Zepp app**. Браузер покаже помилку «localhost» — це нормально. Скопіюй повну адресу з рядка браузера, встав у термінал, Enter.
4. **Bridge у Zepp:** Профіль → Режим розробника → **+** → **Bridge**.
5. **Встановлення** у терміналі:
   ```
   zeus bridge
   ```
   далі в рядку `bridge$`:
   ```
   connect
   install
   ```
   На `connect` вибери Zepp App (Enter). Якщо `install` спитає пристрій — Amazfit Bip 6 (Enter).
6. «Блокнот» з'явиться в списку програм годинника.

Після встановлення codespace можна зупинити (Code → Codespaces → ⋯ → Stop codespace), щоб не витрачати квоту GitHub.

## Оновлення програми

Змінив код → `zeus bridge` → `connect` → `install`. `appId` у `app.json` не змінюй: за ним годинник впізнає програму, і нотатки зазвичай лишаються після оновлення.

## Якщо щось не так

- **`connect` не бачить телефон:** у Zepp вимкни й увімкни Bridge, перевір інтернет на телефоні та що годинник підключений.
- **`Login information is invalid`:** `npm run login` ще раз.
- **Не ставиться на годинник:** акаунт у `npm run login` і в Zepp app мають збігатися.
- **Запасний шлях:** `zeus preview` малює QR-код у терміналі. Відкрий codespace на іншому екрані (ПК, планшет) і скануй QR у Zepp: Профіль → Режим розробника → значок сканера вгорі праворуч.

## Структура

- `page/index.js` — список нотаток
- `page/view.js` — перегляд, редагування, видалення
- `page/edit.js` — редактор
- `keyboard/` — клавіатура: розкладки, логіка тексту, віджети й дотики
- `utils/store.js` — збереження в `notes.json` на годиннику
- `tools/zepp-login.js` — вхід у Zepp для Codespaces
